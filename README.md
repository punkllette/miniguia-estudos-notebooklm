# 📚 Miniguia de Estudos — NotebookLM

Repositório desenvolvido como atividade da **Digital Innovation One (DIO)** para documentar o processo de estudo e pesquisa utilizando o **NotebookLM**.

## 🎯 Tema escolhido

O tema escolhido para este caderno temático foi **criação e desenvolvimento de hábitos**, tendo como principal referência os conceitos apresentados no livro **Hábitos Atômicos**, de James Clear.

A escolha do tema surgiu do interesse em compreender melhor como pequenos comportamentos realizados de forma consistente podem contribuir para mudanças significativas no longo prazo.

## 🧠 Objetivos de estudo

Os principais objetivos deste projeto são:

* Compreender os fundamentos da criação de hábitos;
* Entender como pequenos comportamentos podem gerar grandes resultados ao longo do tempo;
* Estudar as quatro leis da mudança de comportamento;
* Identificar estratégias práticas para criar bons hábitos;
* Compreender estratégias para reduzir ou eliminar hábitos indesejados;
* Utilizar o NotebookLM como ferramenta de pesquisa, organização e revisão;
* Criar um material de consulta que possa ser reutilizado posteriormente.

## 📖 Sobre o projeto

A proposta foi utilizar diferentes fontes relacionadas ao tema para construir um **segundo cérebro de estudos sobre criação de hábitos**.

As fontes foram inseridas no NotebookLM e utilizadas para realizar perguntas, comparar informações, identificar conceitos importantes e produzir resumos estruturados.

Além do conteúdo final, este repositório documenta parte do processo de elaboração dos prompts, incluindo testes, dificuldades encontradas e melhorias realizadas.

# 🔎 Engenharia de Prompts

Durante o estudo, os prompts foram utilizados para diferentes objetivos: compreensão, resumo, comparação, aplicação prática e revisão.

Um dos princípios utilizados foi evitar perguntas excessivamente genéricas e transformar as dúvidas em perguntas específicas e orientadas ao conteúdo das fontes.

Exemplo de evolução:

**Prompt inicial:**

> Explique o livro Hábitos Atômicos.

Esse prompt produz uma resposta ampla, mas não necessariamente ajuda a estudar de maneira estruturada.

**Prompt aprimorado:**

> Com base exclusivamente nas fontes deste notebook, explique os principais conceitos de Hábitos Atômicos. Organize a resposta em tópicos, apresente exemplos práticos e indique quais fontes sustentam cada conceito.

Esse segundo formato apresenta maior direcionamento e facilita a conferência das informações.

# 💡 Principais aprendizados

Durante a construção do caderno temático, foi possível perceber que o uso de uma IA como ferramenta de estudo funciona melhor quando existe uma boa curadoria das fontes e quando as perguntas são específicas.

O processo também mostrou que não basta solicitar um resumo. É possível utilizar o NotebookLM para fazer perguntas progressivamente mais específicas, comparar conceitos, solicitar exemplos, identificar relações entre diferentes ideias e transformar o conteúdo em materiais de revisão.

Assim, o NotebookLM pode funcionar não apenas como uma ferramenta de respostas, mas como uma ferramenta de **organização e exploração de conhecimento**.

# 📌 Conclusão

Este projeto representa uma experiência prática de utilização de inteligência artificial como ferramenta de apoio aos estudos.

A partir da curadoria de fontes, elaboração de prompts e organização das informações, foi possível transformar diferentes materiais sobre criação de hábitos em um sistema de estudo mais estruturado e reutilizável.

O principal objetivo não foi apenas obter respostas da IA, mas desenvolver um processo de pesquisa no qual as fontes, perguntas, resultados e aprendizados pudessem ser organizados e consultados posteriormente.
